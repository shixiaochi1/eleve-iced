## 目标

## Phase 1: 基础框架（1天）

**文件**：`src/main.rs`, `src/ui/app.rs`

- [ ] 配置Cargo.toml依赖（iced 0.13）
- [ ] 实现基础Iced App结构
- [ ] 1+3布局骨架（IconBar + ChatArea + Drawer）
- [ ] 窗口能弹出来，显示基本布局

## Phase 2: 左侧IconBar（2天）

**文件**：`src/ui/icon_bar.rs`

- [ ] 垂直导航栏（56px宽）
- [ ] 顶部Logo按钮
- [ ] 9个导航图标（Agent、文件、看板、定时任务、工具、学习、频道、用量、调试）
- [ ] 底部设置按钮
- [ ] 激活状态样式（渐变背景 + 指示条）
- [ ] hover动效

---

## Phase 3: 中间聊天区（3天）

**文件**：`src/ui/chat_area.rs`, `src/ui/message_bubble.rs`

- [ ] 标题栏（会话名 + 操作按钮）
- [ ] 消息列表（mock数据）
  - [ ] 用户消息气泡（右对齐，蓝色背景）
  - [ ] AI消息气泡（左对齐，深色背景）
  - [ ] 工具调用卡片（带图标 + 状态）
  - [ ] 代码块（语法高亮样式）
- [ ] 输入区域
  - [ ] 多行文本框
  - [ ] 附件按钮
  - [ ] 发送按钮
- [ ] 滚动行为（自动滚到底部）

---

## Phase 4: 右侧抽屉（2天）

**文件**：`src/ui/drawer.rs`

- [ ] 抽屉容器（280px宽）
- [ ] 可切换面板（文件浏览器/调试/设置等）
- [ ] 关闭按钮
- [ ] 面板内容（mock数据）

---

## Phase 5: 主题和样式（2天）

**文件**：`src/theme.rs`, `src/ui/styles.rs`
